# Working rules for this repo

- Requirements: `SPEC.md`. Build plan: the editable doc "GroceryTracking — Build Plan (v1)" at https://claude.ai/artifact/1fpQ7wHsxMyWxrSXdTrj6e (read it with the Claude Docs tools; the user edits it directly). Re-read the doc before building anything. Keep both up to date as decisions are made.
- **Ask the user before any logical or design decision.** Never assume. Give a suggested default with each question.
- **Don't guess facts.** If unsure about an API, library, or limit, say so or verify first.
- Build **one phase/feature at a time**. After each one, ask the user to test it on their Pixel and confirm it works before moving on.
- Explain things to the user simply and concisely.
